# Project: Digital Business Card (NFC-Ready)

## Vision
A "cutesy-professional" digital business card. It should feel warm and inviting (like a personalized gift) but clean enough for professional networking.

## Core Features
- **Public Profile:** Displays Name, Age, Address, Contact #, Relationship status, Email, and Social Media links.
- **Admin Dashboard:** A protected route where the owner can update all the info above.
- **Link Management:** A section in the Admin Dashboard to see the "Live Link" with a "Copy Link" button for easy NFC writing.

## Tech Requirements
- **Storage:** Use a simple database (like Supabase or Firebase) to ensure the Admin changes actually persist.
- **Styling:** Tailwind CSS. Use a palette of "Soft Cream, Sage Green, and Charcoal" for that cutesy-pro look.
- **UI Elements:** Rounded 'bento-box' style cards, subtle box shadows, and springy hover animations.
