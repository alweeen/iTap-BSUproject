# Style Guide: "Cutesy Professional"

## Visual Rules
- **Border Radius:** `2xl` or `3xl` for all containers (extra rounded).
- **Typography:** A mix of a playful serif for names (like 'Outfit' or 'Quicksand') and a clean sans-serif for contact info.
- **Interactions:** Buttons should have a slight "scale-up" effect on hover.
- **NFC Ready:** The profile URL should be clean (e.g., `/profile/username`) to keep the NFC payload small.

UI Components:

The Card: Use a "Glassmorphism" effect—white background with 70% opacity and a backdrop-blur-md filter.

Colors: Use Soft Lavender (#E6E6FA) for the background and Mint Green (#98FF98) for the "Copy Link" buttons.

Icons: Use Lucide-React icons. They are thin, clean, and professional.
